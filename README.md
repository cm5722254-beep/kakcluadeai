# kakcluadeai

[![Release](https://img.shields.io/badge/release-v1.0.0-blue.svg)](https://github.com/cm5722254-beep/kakcluadeai)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)

Claude AI Management Suite & Pro Studio IDE for Windows.

## Highlights
- **Real Code Execution**: Execute Python, JavaScript, TypeScript, and batch files directly in integrated terminal (F5).
- **Pro Monaco Editor**: Full syntax highlighting, auto-formatting (Shift+Alt+F), and multi-tab editing.
- **Full File Management**: Create new files, folders, rename, delete, and explore via context menu.
- **Khmer Localization**: Full dual-language support for English and ភាសាខ្មែរ.
- **Multi-Session Terminal**: Powered by `node-pty` and `xterm.js`.

## Quick Start
- Run `Open-Claude-Code-Studio-IDE.bat` to launch the IDE.
- Run `Open-CHEATZ-ADMIN-CLAUDE-AI.bat` for the Admin Dashboard.
