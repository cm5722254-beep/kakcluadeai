# kakcluadeai

Claude AI Management Suite & Studio IDE:
- **Claude Studio**: Web-based IDE & Chat Studio for Claude Code.
- **Cheatz Admin Claude AI**: Admin Dashboard & Command Center.
- **FCC Desktop App**: Electron Desktop wrapper & runner for Free Claude Code.
- **Quick Launch Scripts**: Direct Windows `.bat` launchers.

## Components
- `claude-studio/`: Claude Code Studio Web IDE
- `cheatz-admin-claude-ai/`: Admin Management App
- `fcc-desktop-app/`: Free Claude Code Desktop Application
- Launcher scripts:
  - `Open-CHEATZ-ADMIN-CLAUDE-AI.bat`
  - `Open-Claude-Code-Studio-IDE.bat`
  - `Open-Claude-Code-Manager.bat`
  - `Run-CHEATDABBER-KING.bat`
  - `run-fcc-claude.bat`
  - `run-fcc-server.bat`
