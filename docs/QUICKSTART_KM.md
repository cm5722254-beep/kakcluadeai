# ការណែនាំរហ័សជាភាសាខ្មែរ (Quickstart Khmer)

### របៀបប្រើប្រាស់ Claude Code Studio IDE:
1. ចុច **Run Code** ឬចុច **F5** ដើម្បីដំណើរការកូដក្នុង Terminal
2. ចុច **Ctrl+S** ដើម្បីរក្សាទុកឯកសារ
3. ចុច Right-Click លើ Explorer ដើម្បីបង្កើត New File ឬ New Folder
4. ប្រើប្រាស់ AI Assistant ដើម្បីសួរសំណួរជាភាសាខ្មែរ ឬអង់គ្លេស
