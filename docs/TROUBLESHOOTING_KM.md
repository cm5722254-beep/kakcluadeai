# ការដោះស្រាយបញ្ហាជាភាសាខ្មែរ (Troubleshooting Khmer)

### បញ្ហាទូទៅ និងដំណោះស្រាយ:
1. **Server មិនដើរ**: ចុច "Start Server" នៅរបារខាងលើ ឬដំណើរការ `run-fcc-server.bat`
2. **Run កូដមិនឆ្លើយតប**: ពិនិត្យមើលថាតើ Node.js ឬ Python បានដំឡើងត្រឹមត្រូវឬនៅ
3. **រក្សាទុកមិនបាន**: ពិនិត្យសិទ្ធិ Folder (Permission) ក្នុង Windows
